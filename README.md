# ScarletProbe

Тестовое iOS-приложение для проверки, **какие возможности iOS реально работают после сайдлоада через Scarlet** (установка с переподписью чужим/своим сертификатом и профилем).

Многие возможности (push, HealthKit, App Group, Live Activity, виджет, фоновые режимы и т.д.) зависят от entitlements и provisioning-профиля. При переподписи через Scarlet часть прав обычно **срезается или заменяется** — и приложение как раз показывает, что осталось рабочим, а что нет. Красный/жёлтый статус теста — это ожидаемый и полезный результат проверки, а не баг приложения.

**Mac не нужен.** Проект собирается целиком в GitHub Actions; у вас на руках оказывается готовый неподписанный `.ipa`, который дальше подписывает и ставит Scarlet.

## Как собрать

Сборка выполняется workflow `.github/workflows/build.yml`.

Запустить можно двумя способами:

1. **Push в ветку `main`** — сборка стартует автоматически.
2. **Вручную**: вкладка **Actions** → слева workflow **«Build unsigned IPA»** → кнопка **Run workflow** → выбрать ветку → **Run workflow** (это `workflow_dispatch`).

Что делает workflow:

- выбирает самый новый установленный Xcode (нужен SDK iOS 26) и печатает `xcodebuild -version` и список SDK;
- ставит XcodeGen (`brew install xcodegen`) и генерирует `ScarletProbe.xcodeproj` из `project.yml` (`.xcodeproj` в репозиторий **не коммитится**);
- выполняет `xcodebuild archive` **без подписи** (`CODE_SIGNING_ALLOWED=NO`, `CODE_SIGNING_REQUIRED=NO`, пустые `CODE_SIGN_IDENTITY`/`CODE_SIGN_ENTITLEMENTS`/`DEVELOPMENT_TEAM`);
- достаёт `ScarletProbe.app` из архива, кладёт в `Payload/` и архивирует в `ScarletProbe.ipa`;
- загружает `ScarletProbe.ipa` как artifact (+ лог сборки).

## Как скачать .ipa

**Actions** → открыть нужный run → секция **Artifacts** внизу → скачать **`ScarletProbe-ipa`** (внутри `ScarletProbe.ipa`). Если сборка упала — там же лежит `ScarletProbe-build-log` с полным логом `xcodebuild`.

## Как установить через Scarlet

1. Перекинуть `ScarletProbe.ipa` на устройство (AirDrop, облако, файловый менеджер).
2. Открыть **Scarlet** → импортировать `.ipa`.
3. Подписать своим или чужим сертификатом/профилем (как обычно для Scarlet).
4. Установить и доверить профилю в `Настройки → Основные → VPN и управление устройством`.

> Bundle ID приложения — `com.local.scarletprobe`, виджета — `com.local.scarletprobe.widget`.

## Структура проекта

```
project.yml                     # описание проекта для XcodeGen (.xcodeproj генерируется из него)
ScarletProbe/
  App/                          # точка входа, AppDelegate, корневой экран
  Core/                         # ядро: протокол ProbeTest, реестр, логгер, стор, результат
  Probes/                       # сами тесты, сгруппированы по темам
    Notifications/              # уведомления, push, AlarmKit, фоновое обновление
    Health/                     # CoreMotion (шаги), HealthKit
    Audio/                      # аудиосессия поверх музыки
    System/                     # камера/фото, сканер, сеть, keychain
    …                           # геолокация, карта, озвучка, Now Playing, речь, Live Activity
  Resources/                    # Info.plist, ScarletProbe.entitlements
Extensions/
  Shared/                       # AppGroup.swift — общие константы (App Group)
  AppIntents/                   # AppIntent «Отметить задачу» (видимость в «Командах»)
  ScarletProbeWidget/           # WidgetKit-расширение (виджет) + Info.plist, entitlements
.github/workflows/build.yml     # CI-сборка неподписанного .ipa
```

Таргеты: приложение **ScarletProbe** (схема `ScarletProbe`) и встраиваемое расширение-виджет **ScarletProbeWidget**. Схема приложения тянет виджет за собой, поэтому `xcodebuild archive` по схеме `ScarletProbe` собирает оба таргета.

## Чек-лист ручной проверки

На экране приложения — список тестов. У каждого: название, кнопка **«Запустить»**, статус (✅ работает / ❌ не работает / ⚠ частично) и детали/ошибка. Часть тестов открывает отдельный экран кнопкой **«Открыть»**. Внизу — **«Запустить все»** и **«Экспорт лога»**.

Что нужно сделать физически для каждой группы:

1. **Локальные уведомления** — разрешить уведомления в системном запросе; свернуть приложение и подождать ~5 сек (разовое), затем проверять каждые 60 сек (повтор, отменяется кнопкой); проверить уведомление с action-кнопками.
2. **Шаги CoreMotion** — разрешить доступ к движению; походить с телефоном, следить за живым обновлением счётчика.
3. **HealthKit** — в системном запросе разрешить шаги/калории/вес; посмотреть, прочитались ли шаги и записался ли тестовый вес (точная ошибка — в деталях, если переподпись срезала HealthKit).
4. **Геолокация** — разрешить сначала «При использовании», затем поднять до «Всегда»; **свернуть приложение и походить**, потом вернуться и посмотреть, сколько точек пришло в фоне.
5. **MapKit** — разрешить геопозицию; открыть экран теста, дождаться построения пешего маршрута на 1 км, проверить расстояние и шаги маршрута на карте.
6. **Голос поверх музыки** — **включить музыку в Apple Music**, запустить тест (фразы по-русски и по-турецки должны звучать поверх музыки с приглушением); затем **свернуть приложение в течение 10 сек** и проверить, говорит ли оно в фоне.
7. **Now Playing Apple Music** — **включить трек в Apple Music**, разрешить доступ к медиатеке, запустить тест, проверить название/артиста.
8. **Remote push** — запустить тест; проверить, пришёл ли **device token** (или полная ошибка `registerForRemoteNotifications`, если aps-environment срезан переподписью).
9. **AlarmKit** — разрешить AlarmKit; дождаться будильника через 1 минуту и срабатывания таймера.
10. **Фоновое обновление** — запустить тест (планирует `BGAppRefreshTask`); **свернуть приложение надолго**, вернуться и посмотреть историю запусков фоновой задачи.
11. **Камера и фото** — разрешить камеру и фото; снять/выбрать фото, проверить сохранение в Documents.
12. **Сканер штрихкодов** — открыть экран сканера, **навести камеру на штрихкод EAN-13**, проверить распознанный код.
13. **Сеть** — запустить тест; проверить статусы HTTPS-запроса на `example.com` и HTTP-запроса на тестовый домен из ATS-исключения (`neverssl.com`).
14. **Keychain** — запустить тест (запись/чтение/удаление строки выполняются автоматически), проверить статус.
15. **Микрофон и распознавание речи** — разрешить микрофон и распознавание речи; запустить и **говорить ~5 секунд**, проверить распознанный текст и поддержку on-device.
16. **Виджет** — **добавить виджет ScarletProbe на домашний экран** (долгое нажатие → «+»); отметить в отчёте, появился ли он и обновляется ли время (App Group).
17. **Live Activity** — запустить тест; **посмотреть Live Activity на локскрине и в Dynamic Island** (таймер должен обновиться и завершиться).
18. **App Intents / Команды** — открыть системное приложение **«Команды»** и найти действие **«Отметить задачу»**; отметить, видно ли его.
19. **URL-схема** — из Safari или Заметок открыть ссылку **`scarletprobe://test`**; приложение должно открыться и показать алерт (проверка deep link, в т.ч. из ntfy).

## Общий отчёт

Кнопка **«Экспорт лога»** внизу экрана открывает системный **ShareSheet** с текстовым отчётом: версия iOS, модель устройства, дата, результат каждого теста и полные тексты ошибок. Этим отчётом удобно поделиться (заметка, мессенджер, файл).
